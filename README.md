   - OpenCV의 한계를 딥러닝으로 넘어선 기술 진화 과정이 담긴 QA 자동화 프로젝트

### [MaumSeed](https://github.com/Woogie-Gim/MaumSeed)
- 2026.07.10 ~ 2026.08.09 마음씨 (MaumSeed)
  - 매일 밤 작성한 일기를 AI가 분석해 정원에 축복을 내려주고, 그 축복과 날씨에 따라 작물이 성장하는 힐링 정원 게임. 하루를 기록하는 행위가 게임의 성장으로 이어지는 경험을 목표로 기획.
    - Unreal Engine 5 C++ 기반으로 델리게이트(Delegate) 이벤트 브로드캐스트 아키텍처를 설계하여, 입력·그리드·작물·하루 정산·UI·저장 시스템 간 결합도를 낮추고 단방향 이벤트 흐름으로 유지보수성을 확보.
    - 외부 LLM 서버와 HTTP 비동기 통신으로 일기 텍스트를 전송해 축복치를 수신하는 파이프라인을 구축하고, 통신 실패 시 기본 축복치와 안내 문구로 대체하는 폴백(Fallback) 처리로 서버 장애에도 게임 진행이 중단되지 않도록 Fault-Tolerance 확보.
    - 작물 데이터를 DataTable로 분리한 데이터 주도 설계로 12종 작물의 성장 조건·선호 날씨·점수를 코드 수정 없이 조정 가능하게 하고, DataTable 행을 값으로 캐싱하여 런타임 댕글링 포인터를 원천 차단. 성장 판정 외 시점에는 Tick을 비활성화하는 연산 최적화 적용.

    - DirectX 12 로우레벨 API로 렌더 파이프라인과 GPU 리소스를 직접 관리하는 3D 전시관 렌더러를 구축하고 수신 이미지를 업로드 힙 경유 및 리소스 배리어 전환으로 GPU 텍스처에 실시간 스트리밍하는 파이프라인을 설계.
    - 업로드 버퍼를 1회 생성 후 재사용하도록 최적화하여 연속 전송 시 발생하는 GPU 리소스 수명 충돌 크래시를 원천 차단.
    - TCP가 메시지 경계를 보장하지 않는 문제에 대응해 매직 넘버·타입·페이로드 크기 기반의 애플리케이션 레벨 프레이밍 프로토콜을 설계하고 요청 바이트를 전량 처리할 때까지 반복하는 송수신 루프로 대용량 이미지 전송의 무결성을 확보.
    - 블로킹 수신을 별도 스레드로 분리하고 뮤텍스 동기화로 렌더 프레임 저하 없이 실시간 통신을 처리.
    - 언리얼이 기본 제공하지 않는 안드로이드 네이티브 카메라·갤러리를 UPL 코드 주입과 JNI 양방향 브릿지로 연동하고 촬영본을 갤러리 선택과 동일한 수신 경로로 재사용하도록 설계하여 신규 코드 표면적을 최소화. 리소스 경로를 실행 파일 기준 상대 경로로 전환하고 빌드 후 이벤트로 자동 복사되게 하여 환경 종속성을 제거.
